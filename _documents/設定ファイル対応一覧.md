# 設定ファイル対応一覧

環境変数で指定できるアプリの設定は、`App_Data/Parameters` の JSON からも指定できます。
ファイル内では次の短いキー、または環境変数と同じキーを使用できます。
既存の `Security.json` の `Password*`、`Analytics.json` の `Analytics*`、
CAPTCHA の `Captcha*` は環境変数と同名のキーで指定します。
ASP.NET Core のホスト設定は従来どおり `appsettings.json` で指定します。

優先順位は従来と同じく **`.local.json` ＞ 環境変数 ＞ `.json`** です。
ファイルを変更したらアプリを再起動してください。
同じファイルで短いキーと環境変数名の両方を指定した場合は、短いキーが優先します。
短いキーの `null`・空文字は未指定として扱い、`false`・`0` は指定値として扱います。
同梱の新規ファイルは `null` の例なので、アプリの既定値を変更しません。

## 指定例

`Rds.local.json`:

```json
{
  "Dbms": "Sqlite",
  "UserConnectionString": "Data Source=App_Data/questionnaire.db"
}
```

`Mail.local.json`:

```json
{
  "Enabled": true,
  "Provider": "Smtp",
  "SmtpHost": "smtp.example.jp",
  "SmtpPort": 587,
  "SmtpSecurity": "StartTls",
  "FromAddress": "survey@example.jp"
}
```

秘密情報も同じ方法で指定できます。`.local.json` は本番でも利用できる運用者用ファイルです。
Git へコミットせず、アプリの実行ユーザーと運用者だけに読み取りを許可し、更新時に退避・復元します。
ファイルをブラウザへ配信しないでください。環境変数・Key Vault での指定も引き続き利用できます。

## 秘密鍵の生成

`SecretKey`（環境変数では `QUESTIONNAIRE_SECRET_KEY`）は必須です。
32 バイトの暗号学的乱数を Base64 で生成する機能を組み込んでいます。
配布 ZIP を展開した場所で次を実行すると、DB・Web サーバーを起動せず、設定ファイルを作成します。

```bash
dotnet VehicleVision.PleasanterTools.Questionnaire.Web.dll --generate-secret-key --output App_Data/Parameters/Security.local.json
```

既存ファイルは内容にかかわらず上書きせず、終了コード 1 で停止します。
`Security.local.json` が既にある場合は、従来の `--generate-secret-key` で鍵を生成し、
そのファイルの `SecretKey` へ設定してください。鍵を失うと登録済みの二要素認証の復号ができません。
既存環境の鍵は作り直さず、バックアップと更新時の引き継ぎを行ってください。
ファイル保存時は鍵を端末へ表示しません。Unix では所有者だけが読み書きできる権限で作成します。
Windows では保存先の ACL を引き継ぐため、アプリ実行ユーザーと運用者に権限を制限してください。

## 本体との対応

Pleasanter 本体と同じ配置・用途別ファイル・`//キー名` の説明方式を採用しています。
本体のコード・設定ファイルはコピーしていません。
`Rds.json` の `Dbms`・`UserConnectionString`、`Mail.json` の `SmtpHost`・`SmtpPort`・
`SmtpUserName`・`SmtpPassword` は本体と同じ項目名です。
値・単位・選択肢は本アプリの既存設定に従います。たとえば `Dbms` は `PostgreSql`、
`Provider` はメールでは `Smtp`・`AmazonSes`・`AzureCommunicationServices` です。
本体の `Rds.Provider`（Local 等）と、本アプリの DB 種別は異なります。
本体の設定一式をそのまま流用するための互換機能ではありません。

確認根拠（2026-10-17）:

- 参照ソース: `_reference/Implem.Pleasanter/Implem.DefinitionAccessor/Initializer.cs` の
  `JsonFilePath`・`ApplyPatchedEnvironmentDefaults`、本体の `App_Data/Parameters/Rds.json`・`Mail.json`
  （固定コミット `1b7b6e6c930cf6a40c89b0c8c692a63177289bef`）。
- 起動済み公式イメージ `implem/pleasanter:1.5.9.0` の `/app/App_Data/Parameters` に
  用途別 JSON が存在すること、`Rds.json` の項目名を読み取り確認。
- 上書き順序は本アプリの既存仕様を維持しています。
